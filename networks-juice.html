Endterm: 11 task types

Each task type starts with fresh numbers. Type your answer and check it, then press New numbers to repeat the same type until it is automatic.

One method solves tasks 1 to 8

  1. Interesting octet. Split the prefix into 8s. /20 = 8 + 8 + 4, so the 3rd octet.
  2. Block size. 256 minus the mask value in that octet.
  3. Network. Largest multiple of the block that is not above the host's value. Octets to the right become 0.
  4. Broadcast. Next network minus 1. Octets to the right become 255.
  5. Range. Network + 1 to broadcast - 1.

Hosts: 2^h - 2, where h = 32 - prefix

Subnets: 2^borrowed, with no minus 2

VLSM: largest first, a router link is a /30

IPv6 /64 subnets: 2^(64 - prefix), counted in hex

One packet is the whole course

Full lesson
  1. DHCPGets IP, mask, gateway, DNS server. UDP 67/68.
  2. DNSTurns the name into an IP. Port 53.
  3. Routing decisionSame subnet: go direct. Otherwise: gateway.
  4. ARP or NDFinds the MAC of the next hop only.
  5. SwitchForwards the frame by destination MAC.
  6. RouterLongest prefix, TTL - 1, builds a new frame.
  7. TCP, TLS, HTTPSYN, SYN-ACK, ACK, then encrypt, then request.

IP addresses stay end to end. MAC addresses change at every hop. NAT is the exception that rewrites IP.

Sending

Data + TCP header = segment. + IP header = packet. + Ethernet header and FCS = frame. Then bits.

Who writes the rules

IEEE: Ethernet, Wi-Fi. IETF: RFCs. IANA: ports and numbers. ICANN: names. TIA/EIA: cabling.

Ethernet and switching

Full lesson

What a switch does

  1. Learns the source MAC on the arrival port.
  2. Looks up the destination MAC.
  3. Known: forward. Same port: filter.
  4. Unknown or broadcast: flood the VLAN, except the incoming port.

Numbers

  • MAC: 48 bits. Broadcast ff:ff:ff:ff:ff:ff
  • Frame 64 to 1518 bytes, payload 46 to 1500
  • FCS detects errors and never repairs
  • EtherType: 0x0800 IPv4, 0x0806 ARP, 0x86DD IPv6

Domains

Each switch port is one collision domain. Each VLAN is one broadcast domain. VLANs need Layer 3 routing to talk. STP stops loops because frames have no hop counter.

Forwarding and access

Store-and-forward checks FCS. Cut-through starts early. Fragment-free waits for 64 bytes. CSMA/CD is legacy wired, CSMA/CA is Wi-Fi.

IP and routing

Full lesson

Choosing a route

  1. Longest prefix always first.
  2. Administrative distance only for the same prefix.
  3. Metric within one protocol.

Codes: C connected, L local, S static, O OSPF. Defaults: 0.0.0.0/0, ::/0.

IP itself

  • Connectionless, best effort, media independent
  • IPv4 header 20+ bytes, IPv6 fixed 40
  • Routers decrement TTL or Hop Limit
  • IPv6 routers never fragment
  • Protocol field: ICMP 1, TCP 6, UDP 17
R1(config)# ip route 192.168.20.0 255.255.255.0 10.0.0.2
R2(config)# ip route 192.168.10.0 255.255.255.0 10.0.0.1   ! return path too

ARP, Neighbor Discovery, and which table

Full lesson

ARP (IPv4)

Request is broadcast, reply is unicast. Sits straight in Ethernet with no port. For a remote destination you ARP for the gateway.

ND (IPv6, over ICMPv6)

RS 133, RA 134, NS 135, NA 136, Redirect 137. DAD uses NS to check an address is unused. Solicited-node: ff02::1:ff + last 24 bits.

Writing an address

  • Drop leading zeros in a hextet, never trailing
  • :: only once, on the longest zero run
  • Expand: 8 minus the groups you can see

Getting an address (the RA decides)

  1. SLAAC: everything from the RA
  2. SLAAC + stateless DHCPv6: address from RA, DNS from DHCPv6
  3. Stateful DHCPv6: address from the server

The default gateway is always the router's link-local, learned from the RA.

EUI-64

Split the MAC, insert ff:fe, flip the 7th bit. No ff:fe in the middle means the ID is random.

Transition

Dual stack runs both. Tunneling carries one inside the other. Translation (NAT64) converts between them.

R1(config)# ipv6 unicast-routing
R1(config)# interface g0/0/0
R1(config-if)# ipv6 address 2001:db8:acad:1::1/64
R1(config-if)# ipv6 address fe80::1 link-local
R1(config-if)# no shutdown

ICMP and testing

Full lesson

Test in this order

Loopback, then gateway, then remote IP, then hostname, then the application. The first failure points at the cause.

Know the limits

Ping proves one ICMP exchange. Traceroute raises TTL and reads Time Exceeded. * * * is a silent router, not a broken path. ICMP has no ports.

The rules

  • Open: SYN, SYN-ACK, ACK. Close: FIN and ACK each way. RST aborts.
  • ACK = first byte + bytes received
  • SYN and FIN each consume one sequence number
  • Receive window protects the receiver, congestion window protects the network
  • MSS 1460 = 1500 - 20 - 20
  • Ports: well-known 0-1023, registered 1024-49151, dynamic 49152-65535

DHCP is DORA

Discover (0.0.0.0 to 255.255.255.255), Offer, Request, Ack. Never lease the network or broadcast address.

DNS records

A IPv4, AAAA IPv6, MX mail, NS name server, CNAME alias, PTR reverse. The recursive resolver walks root, TLD, authoritative. Test with nslookup.

HTTP

GET, POST, PUT, DELETE. Codes: 200 OK, 301 moved, 403 forbidden, 404 not found, 500 server error. Stateless, so sites use cookies.

NAT and PAT

Static is one to one, dynamic uses a pool, PAT shares one IP using ports. NAT is not encryption.

Physical layer and Wi-Fi

Full lesson

Media

  • UTP: cheap, common, usually 100 m
  • Fiber: immune to EMI. Single-mode long, multimode short
  • Straight-through when exactly one end is a switch, crossover otherwise, rollover for console
  • Attenuation: loss over distance. Crosstalk: coupling between wires

Wi-Fi

  • SSID is the name, BSSID the AP radio
  • 2.4 GHz channels 1, 6, 11 avoid overlap
  • Wi-Fi 4 = n, 5 = ac, 6 = ax
  • RSSI is strength, SNR is signal against noise

A 10 MB file on 20 Mb/s: 80 Mb / 20 = 4 s. MB is bytes, Mb is bits, a factor of 8. Bandwidth is capacity, throughput is what you got, jitter is delay variation.

Security

Full lesson

Language

  • CIA: confidentiality, integrity, availability
  • AAA: authentication, authorization, accounting
  • Hash is one-way, encryption is reversible
  • IDS alerts, IPS blocks
  • ACL: first match wins, implicit deny at the end. Wildcard is the inverted mask
  • Least privilege, defense in depth

Attacks to name

  • Virus attaches, worm spreads alone, Trojan disguises
  • DoS and DDoS exhaust resources
  • ARP, DHCP and DNS spoofing plant false answers
  • Evil twin imitates a trusted AP
  • Phishing and tailgating target people
  • SQL injection: use parameterized queries

Wi-Fi security

WEP and TKIP are obsolete. WPA2 AES, WPA3 uses SAE. 802.1X: supplicant, authenticator, RADIUS server. Hiding the SSID is not security.

Design

DMZ for public services. VLANs separate, firewalls enforce. FAR is false accept, FRR is false reject. SSH instead of Telnet.

Resilience and backups

Full lesson

RAID (not a backup)

  • 0: stripe, no protection
  • 1: mirror
  • 5: single parity, survives 1 disk
  • 6: dual parity, survives 2
  • 10: stripe of mirrors

Backups and targets

  • Incremental restore: full + every incremental
  • Differential restore: full + latest differential
  • RPO: data you can lose. RTO: time to come back
  • 99.999% is about 5.26 minutes a year
  • N+1 is one spare. HSRP protects the gateway

Method: identify, theorize, test, fix, verify, document. Bottom-up starts at the cable, top-down at the application, divide-and-conquer in the middle.

Top traps

  1. Subnet counts have no minus 2. Host counts do.
  2. 62 usable fits a /26, but 63 hosts needs a /25.
  3. The router-to-router link is a subnet too. Size it /30.
  4. VLSM: largest first, always.
  5. An address ending in .0 can be a valid host, for example 172.16.5.0/23.
  6. /20 works in the 3rd octet. Look at the 3rd octet, not the 4th.
  7. IPv6 counts in hex: after 9 comes a, and 10 hex is 16.
  8. IPv6 needs ipv6 unicast-routing or RA and forwarding stop.
  9. A remote destination means you ARP for the gateway, not the server.
  10. The switch learns the source and forwards on the destination.
  11. ACK is the next byte expected, not the last one received.
  12. fe90:: is still link-local. 3001:: is still global.
  13. Ping success does not prove DNS, TLS or the application.
  14. RAID is not a backup. NAT is not encryption.
